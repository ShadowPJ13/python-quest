Construye tu primera web

Un muro de mensajes con Python y Flask que funciona en el navegador. Pruébalo aquí abajo, constrúyelo en 5 pasos y descubre cómo publicar tu app en internet. 🚀

👀

La meta: pruébala aquí mismo

Esto es lo que vas a construir (simulado aquí mismo). ¡Escribe un mensaje y añádelo, bórralo, juega!

🔒 localhost:5000

📌 Muro de mensajes

💡 Tu web real hará exactamente esto, pero servida por tu programa Python con Flask. ¡Vamos a crearla!

1

Tu servidor en 7 líneas

Una web es un programa que escucha peticiones y responde páginas. Primero instala Flask en una terminal:

pip install flask

Ahora crea app.py con esto, ejecútalo (python app.py) y abre localhost:5000 en tu navegador:

from flask import Flask

app = Flask(__name__)

@app.route("/")
def inicio():
    return "<h1>¡Mi primera web con Python! 🐍</h1>"

if __name__ == "__main__":
    app.run(debug=True)
💡 localhost:5000 significa «mi propio ordenador, puerta 5000». debug=True recarga solo al guardar cambios. Para parar el servidor: Ctrl + C en la terminal.

2

Rutas: las calles de tu web

Cada @app.route(...) es una «calle»: cuando alguien la visita, se ejecuta su función. ¡Igual que los comandos del bot! 🤖

@app.route("/adios")
def adios():
    return "<h1>¡Adiós! 👋</h1>"

@app.route("/saludo/<nombre>")
def saludo(nombre):
    return f"<h1>¡Hola, {nombre}! 👋</h1>"
💡 La magia: <nombre> captura lo que escriban en la dirección y lo entrega como parámetro. /saludo/Ana → nombre = "Ana".

Plantillas: diseño separado

Mezclar HTML dentro del Python se vuelve un lío. La solución: guardar el diseño en archivos plantilla dentro de una carpeta llamada templates, y rellenar huecos con {{ ... }}:

Archivo templates/saludo.html:

<h1>¡Hola, {{ nombre }}! 👋</h1>
<p>Esta página viene de un archivo.</p>

En app.py:

from flask import render_template

@app.route("/saludo/<nombre>")
def saludo(nombre):
    return render_template("saludo.html", nombre=nombre)
💡 Python y diseño, cada uno en su archivo: render_template une la plantilla con tus variables. ¡Así trabajan los profesionales!
🎯 Mini-reto 2: ¿qué hace {{ nombre }} en una plantilla?

4

Formularios: escucha al visitante

Para recibir datos (como un mensaje nuevo) necesitas un formulario y una ruta que lo lea. Hay dos métodos:

MétodoPara qué
GETPedir una página (lo normal al navegar)
POSTEnviar datos (formularios)

El formulario (en la plantilla):

<form action="/nuevo" method="post">
  <input type="text" name="texto" placeholder="Escribe…">
  <button>Añadir</button>
</form>

La ruta que lo recibe (en app.py):

from flask import request, redirect

MENSAJES = []

@app.route("/nuevo", methods=["POST"])
def nuevo():
    texto = request.form.get("texto", "").strip()
    if texto:
        MENSAJES.append(texto)
    return redirect("/")
💡 request.form trae lo escrito (la clave es el name del input). Y redirect("/") devuelve al muro tras guardar.

🗑️ Borrar con rutas dinámicas

Cada mensaje tendrá su botón de borrar. La ruta captura el índice como número con <int:indice>:

@app.route("/borrar/<int:indice>", methods=["POST"])
def borrar(indice):
    if 0 <= indice < len(MENSAJES):
        MENSAJES.pop(indice)
    return redirect("/")

📦 Los archivos finales

Tu proyecto debe quedar con esta estructura (la plantilla va dentro de la carpeta templates):

mi_web/
├── app.py
└── templates/
    └── index.html

app.py:

# app.py — ¡Mi primera web con Flask! 🌐
from flask import Flask, render_template, request, redirect

app = Flask(__name__)

MENSAJES = ["¡Bienvenido al muro! 🎉"]


@app.route("/")
def inicio():
    return render_template("index.html", mensajes=MENSAJES)


@app.route("/saludo/<nombre>")
def saludo(nombre):
    return f"<h1>¡Hola, {nombre}! 👋</h1><p><a href='/'>Volver al muro</a></p>"


@app.route("/nuevo", methods=["POST"])
def nuevo():
    texto = request.form.get("texto", "").strip()
    if texto:
        MENSAJES.append(texto)
    return redirect("/")


@app.route("/borrar/<int:indice>", methods=["POST"])
def borrar(indice):
    if 0 <= indice < len(MENSAJES):
        MENSAJES.pop(indice)
    return redirect("/")


if __name__ == "__main__":
    app.run(debug=True)

▶️ Ejecútala

  1. Crea la carpeta mi_web con los dos archivos (plantilla dentro de templates/).
  2. En una terminal, en esa carpeta: python app.py
  3. Abre localhost:5000 en tu navegador. ¡Tu web vive! 🎉

🌍 Publícala en internet (gratis)

Tu web ahora solo existe en tu PC. Para que cualquiera la visite, súbela a un hosting gratuito como Render o PythonAnywhere: creas cuenta, subes tus archivos, pones flask en los requisitos… ¡y te dan una dirección pública! (Cada plataforma tiene su guía paso a paso.)

🚀 Retos de ampliación

  1. Memoria: guarda los mensajes en un archivo (¡como en el taller de la app!) para no perderlos al reiniciar.
  2. API JSON: crea /api/mensajes que devuelva la lista con jsonify.
  3. Más páginas: añade /about contando quién eres.
  4. Estilo: cambia colores, añade emojis, hazla tuya. 🎨
