Tu primer comando: /start

Los bots escuchan con decoradores: líneas con @ que dicen «cuando pase ESTO, ejecuta esta función». mensaje trae lo que escribió el usuario:

@bot.message_handler(commands=["start"])
def saludar(mensaje):
    bot.reply_to(mensaje, "¡Hola! Soy tu primer bot 🎉\nEscribe /ayuda para ver lo que sé hacer.")


@bot.message_handler(commands=["ayuda"])
def ayuda(mensaje):
    bot.reply_to(mensaje,
        "Puedo hacer esto:\n"
        "/start - Saludarme\n"
        "/ayuda - Ver esta ayuda\n"
        "/dado - Tirar un dado 🎲\n"
        "/suma 5 3 - Sumar números ➕\n"
        "/nota comprar pan - Guardar una nota 📝\n"
        "/notas - Ver tus notas\n"
        "Y si me hablas… ¡te respondo! 💬")
💡 Pega estas funciones antes del bot.infinity_polling() final. bot.reply_to() responde al mensaje que llegó. ¡Pruébalo en Telegram!

Lee lo que escriben: /suma

¿Y si el comando trae datos, como /suma 5 3? El texto completo llega en mensaje.text. Lo partimos con .split() → ["/suma", "5", "3"] y cogemos los trozos [1] y [2]:

@bot.message_handler(commands=["suma"])
def suma(mensaje):
    try:
        partes = mensaje.text.split()
        a = float(partes[1])
        b = float(partes[2])
        bot.reply_to(mensaje, f"➕ {a} + {b} = {a + b}")
    except (IndexError, ValueError):
        bot.reply_to(mensaje, "Úsalo así: /suma 5 3")
💡 El try/except protege de dos meteduras de pata: escribir pocos números (IndexError) o escribir letras (ValueError). ¡Un bot profesional nunca se cuelga!

📝 Notas por usuario

Guardaremos notas en un diccionario donde la clave es mensaje.chat.id (el nº que identifica a cada persona). ¡Así cada usuario tiene SUS notas!

notas = {}  # chat_id -> lista de notas (ponlo arriba, con el token)


@bot.message_handler(commands=["nota"])
def guardar_nota(mensaje):
    texto = mensaje.text.replace("/nota", "", 1).strip()
    if not texto:
        bot.reply_to(mensaje, "Escribe algo: /nota comprar pan")
        return
    chat = mensaje.chat.id
    if chat not in notas:
        notas[chat] = []
    notas[chat].append(texto)
    bot.reply_to(mensaje, f"📝 Nota guardada ({len(notas[chat])} en total).")


@bot.message_handler(commands=["notas"])
def ver_notas(mensaje):
    chat = mensaje.chat.id
    if chat not in notas or not notas[chat]:
        bot.reply_to(mensaje, "(sin notas)")
        return
    lineas = [f"{i + 1}. {n}" for i, n in enumerate(notas[chat])]
    bot.reply_to(mensaje, "📝 Tus notas:\n" + "\n".join(lineas))
🎯 Mini-reto 4: ¿por qué notas es un diccionario con chat.id?

💬 Responder cuando hablan (sin comandos)

Esta función atrapa todo lo demás: mira si el texto contiene palabras clave y si no, hace eco. El truco: excluimos los comandos con not ... startswith("/") (¡si no, respondería dos veces a cada comando!).

@bot.message_handler(func=lambda m: not m.text.startswith("/"), content_types=["text"])
def responder(mensaje):
    texto = mensaje.text.lower()
    if "hola" in texto:
        bot.reply_to(mensaje, "¡Hola, humano! 👋")
    elif "python" in texto:
        bot.reply_to(mensaje, "¡Python es el mejor lenguaje! 🐍")
    elif "gracias" in texto:
        bot.reply_to(mensaje, "¡De nada! 😊")
    else:
        bot.reply_to(mensaje, f"Me has dicho: {mensaje.text}")
💡 lambda m: ... es una mini-función sin nombre: «responde a todo lo que NO empiece por /». Y content_types=["text"] ignora stickers y fotos para que no lo rompan.
