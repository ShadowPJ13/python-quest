# 🐍 Python Quest

**Aprende Python jugando.** Un juego web de 33 niveles y 8 mundos, con manual completo,
talleres guiados y página de contacto. Sin instalar nada: funciona en cualquier navegador.

🌐 **Jugar online:** https://shadowpj13.github.io/python-quest/

## 📂 Contenido

| Archivo | Qué es |
|---|---|
| `index.html` | 🎮 El juego: 33 niveles, 8 mundos, 11 logros, guardado automático |
| `manual.html` | 📖 Manual de Python en 22 capítulos (de `print()` a Flask) |
| `taller.html` | 🛠️ Taller: crea tu app de tareas con `tkinter` |
| `taller-bot.html` | 🤖 Taller: crea tu bot de Discord |
| `taller-web.html` | 🌐 Taller: crea tu primera web con Flask |
| `contacto.html` | ✉️ Formulario de contacto (funciona con Formspree) |

## 💻 Uso en local

No necesita servidor ni instalación. Basta con abrir `index.html` en el navegador…
o servir la carpeta para probarlo como una web de verdad:

```bash
cd python-quest
python -m http.server 8000
# abrir http://localhost:8000
```

## 🔄 Cómo actualizar la web (para el autor)

1. Edita los archivos `.html` en tu PC.
2. Súbelos al repositorio (arrastrar a GitHub web o `git push`).
3. GitHub Pages republica solo en 1–2 minutos. Listo.
