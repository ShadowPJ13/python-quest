Los cimientos: datos y mostrar

Crea un archivo llamado mis_tareas.py. Lo primero: decidir cómo guardamos los datos. Cada tarea será un diccionario con su texto y si está hecha, y todas vivirán en una lista:

# mis_tareas.py — ¡Mi primera app! 🎉

def mostrar_tareas(tareas):
    if not tareas:
        print("(sin tareas)")
        return
    for i in range(len(tareas)):
        marca = "✓" if tareas[i]["hecha"] else "○"
        print(f"{i + 1}. [{marca}] {tareas[i]['texto']}")


# Datos de prueba (los quitaremos en el paso 4):
tareas = [
    {"texto": "Aprender Python", "hecha": True},
    {"texto": "Hacer mi primera app", "hecha": False},
]
mostrar_tareas(tareas)
1. [✓] Aprender Python 2. [○] Hacer mi primera app
💡 Trucos usados: if not tareas detecta una lista vacía (¡las listas vacías valen False!), y "✓" if ... else "○" elige la marca en una línea.

Añadir tareas

Para añadir necesitamos pedir un texto con input(), limpiarlo con .strip() (quita espacios y el Enter) y meterlo en la lista con .append():

texto = input("Nueva tarea: ").strip()
if texto:

💡 if texto: evita guardar tareas vacías: un texto vacío "" también vale False. ¡Guarda este trozo! Lo colocaremos dentro del menú en el paso 4.

Completar, borrar y pedir números

Para completar o borrar, el usuario elige un número. Pero int() se rompe si escribes letras… ¡Necesitamos una función a prueba de errores! Presentamos pedir_numero:

def pedir_numero(texto, maximo):
    while True:
        try:
            n = int(input(texto))
            if 1 <= n <= maximo:
                return n
            print(f"Escribe un número del 1 al {maximo}.")
        except ValueError:
            print("Eso no es un número, prueba otra vez.")
💡 Dos cosas nuevas: try/except ValueError atrapa el error si escribes letras, y Python permite comparar en cadena: 1 <= n <= maximo significa «entre 1 y el máximo».

Con eso, completar y borrar son fáciles. Fíjate en el n - 1: ¡el usuario cuenta desde 1 pero Python desde 0!

mostrar_tareas(tareas)
n = pedir_numero("¿Cuál completaste? ", len(tareas))
tareas[n - 1]["hecha"] = True
print("¡Bien hecho! 🎉")
mostrar_tareas(tareas)
n = pedir_numero("¿Cuál borras? ", len(tareas))
borrada = tareas.pop(n - 1)
print(f"Borrada: {borrada['texto']}")

El menú: el corazón de la app

Ahora unimos TODAS las piezas en la función main(): un while True que muestra opciones y reacciona con if/elif. La opción 5 sale con break:

def main():
    tareas = []  # provisional: en el paso 5 cargaremos el archivo
    print("=== MIS TAREAS ✅ ===")
    while True:
        print("\n1. Ver  2. Añadir  3. Completar  4. Borrar  5. Salir")
        opcion = input("Elige: ")
        if opcion == "1":
            mostrar_tareas(tareas)
        elif opcion == "2":
            texto = input("Nueva tarea: ").strip()
            if texto:
                tareas.append({"texto": texto, "hecha": False})
                print("¡Añadida!")
        elif opcion == "3":
            if not tareas:
                print("(sin tareas)")
            else:
                mostrar_tareas(tareas)
                n = pedir_numero("¿Cuál completaste? ", len(tareas))
                tareas[n - 1]["hecha"] = True
                print("¡Bien hecho! 🎉")
        elif opcion == "4":
            if not tareas:
                print("(sin tareas)")

Memoria infinita: archivos 💾

Tu app casi está lista… pero tiene amnesia: al cerrarla, ¡olvida todo! La cura: guardar en un archivo tareas.txt. Con open() y with (que lo cierra solo):

ModoSignifica
"r"Read: leer (falla si no existe)
"w"Write: escribir (crea el archivo o borra lo anterior)
"a"Append: añadir al final sin borrar

Guardaremos cada tarea en una línea: [x] Estudiar o [ ] Comprar pan. Añade estas dos funciones al principio del archivo:

ARCHIVO = "tareas.txt"


def guardar_tareas(tareas):
    with open(ARCHIVO, "w", encoding="utf-8") as f:
        for t in tareas:
            marca = "[x]" if t["hecha"] else "[ ]"
            f.write(f"{marca} {t['texto']}\n")


def cargar_tareas():
    tareas = []
    try:
        with open(ARCHIVO, "r", encoding="utf-8") as f:
            for linea in f:
                linea = linea.strip()
                if linea:
                    hecha = linea.startswith("[x]")
                    texto = linea[3:].strip()
                    tareas.append({"texto": texto, "hecha": hecha})
    except FileNotFoundError:
        pass  # primera vez: aún no hay archivo
    return tareas

▶️ Cómo ejecutarla en tu PC

  1. Guarda el código como mis_tareas.py (usa el botón de descarga ⬇).
  2. Abre una terminal en esa carpeta y escribe python mis_tareas.py (o ábrelo en VS Code y pulsa ▶).
  3. Añade tareas, sal… ¡y vuelve a entrar! Seguirán ahí gracias a tareas.txt. 💾

🚀 Retos de ampliación

  1. Contador: al salir, muestra «Te quedan X pendientes» (cuenta las de hecha == False).
  2. Editar: añade la opción 6 para cambiar el texto de una tarea.
  3. Limpiar hechas: opción que borre de golpe todas las completadas (pista: comprensión con if).
  4. ¡Sueña! Con esta misma estructura puedes hacer una app de notas, de gastos o de contraseñas.
