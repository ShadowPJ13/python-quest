Tu primer programa

Python es un lenguaje de programación famoso por ser fácil de leer: su código se parece al inglés. Se usa en videojuegos, inteligencia artificial, webs, ciencia y mucho más.

🖨️ print(): mostrar cosas en pantalla

La función print() muestra un mensaje. El texto (llamado string) va entre comillas:

print("Hola, mundo")
Hola, mundo

Puedes usar comillas dobles "..." o simples '...', ambas valen. También puedes imprimir números y varias cosas separadas por comas:

print('Las comillas simples también sirven')
print(42)
print("Tengo", 25, "años")
Las comillas simples también sirven 42 Tengo 25 años

💬 Comentarios: notas para humanos

Todo lo que va después de # lo ignora Python. Sirve para explicar tu código:

# Esto es un comentario, Python lo ignora
print("Esto sí se ejecuta")  # comentario al final de la línea
⚠️ Errores típicos: Print con mayúscula falla (Python distingue mayúsculas), y olvidar un paréntesis o una comilla da SyntaxError.

Variables y tipos de datos

Una variable es una caja con nombre donde guardas un valor para usarlo después. Se crea con el signo =:

puntos = 100
nombre = "Ada"
print(puntos)
print(nombre)
100 Ada
💡 Nombra tus variables en minúsculas y con guion bajo: puntos_totales. No pueden empezar por número ni llevar espacios o tildes.

La función type() revela el tipo de cualquier valor:

print(type(3.14))

Decisiones: if, elif, else

Con if tu programa decide: ejecuta un bloque de código solo si la condición es verdadera.

edad = 18
if edad >= 18:
    print("Puedes entrar")
    print("¡Bienvenido!")
Puedes entrar ¡Bienvenido!
⚠️ Dos reglas de oro: el if termina con dos puntos : y el bloque va indentado (4 espacios). Sin eso, Python se queja.

🔀 Varios caminos: elif y else

puntos = 75
if puntos >= 90:
    print("A")
elif puntos >= 60:
    print("B")
else:
    print("C")
B

Python prueba las ramas en orden y ejecuta solo la primera que sea verdadera. else es el plan B: se ejecuta si nada anterior cumplió.

💡 Puedes poner if dentro de otro if (anidados), pero no abuses: más de 2 niveles se vuelve difícil de leer.

Bucles: for y while

Los bucles repiten código sin que tengas que escribirlo mil veces.

🔁 for: repetir un nº conocido de veces

El compañero inseparable del for es range(), que genera secuencias de números:

for i in range(3):
    print(i)
0 1 2
⚠️ ¡Ojo! range(3) genera 0, 1, 2: empieza en 0 y excluye el final. Es la trampa más clásica.
UsoGenera
range(5)0, 1, 2, 3, 4
range(2, 6)2, 3, 4, 5
range(0, 10, 2)0, 2, 4, 6, 8 (de 2 en 2)

El for también recorre textos y listas directamente:

for letra in "hola":
    print(letra)
h o l a

⏳ while: repetir MIENTRAS se cumpla algo

n = 3
while n > 0:
    print(n)
    n -= 1
print("¡Despegue!")
3 2 1 ¡Despegue!
⚠️ Si la condición del while nunca se vuelve False, el bucle es infinito y el programa se cuelga. Asegúrate de que algo cambie en cada vuelta (aquí, n -= 1).

🛑 break y continue

  • break → sale del bucle inmediatamente.
  • continue → salta a la siguiente vuelta.
for i in range(10):
    if i == 3:
        break
    print(i)
0 1 2

Una lista guarda varios valores ordenados entre corchetes [ ]:

Tuplas y conjuntos

🔒 Tuplas: listas que no cambian

Van entre paréntesis ( ). Una vez creadas, no se pueden modificar. Ideales para datos fijos (coordenadas, días…):

punto = (10, 20)
print(punto[0])  # 10
# punto[0] = 99  → ¡ERROR! Las tuplas son inmutables
10

🎲 Sets (conjuntos): sin repetidos ni orden

Van entre llaves { }. Eliminan duplicados automáticamente:

colores = {"rojo", "azul", "rojo"}
print(colores)  # {'rojo', 'azul'} → ¡sin repetidos!
colores.add("verde")
print("azul" in colores)  # True
{'rojo', 'azul'} True
💡 Truco famoso: list(set([1, 2, 2, 3])) → [1, 2, 3]. ¡Así se quitan duplicados de una lista!

Diccionarios

Un diccionario guarda pares clave → valor entre llaves. Perfecto para fichas y datos con nombre:

jugador = {"nombre": "Ada", "nivel": 5, "vidas": 3}
print(jugador["nombre"])
print(jugador["nivel"])
Ada 5

✏️ Añadir, cambiar y leer con seguridad

jugador = {"nombre": "Ada", "nivel": 5}
jugador["nivel"] = 6       # modificar
jugador["puntos"] = 100    # añadir nuevo par
print(jugador.get("vidas", 0))  # .get: si no existe, devuelve 0 (sin error)
print("nivel" in jugador)       # True
0 True
⚠️ jugador["vidas"] daría KeyError si la clave no existe. Usa .get(clave, valor_por_defecto) para evitar sustos.

🔁 Recorrer un diccionario

notas = {"mat": 9, "lengua": 7}
for materia, nota in notas.items():
    print(f"{materia}: {nota}")
mat: 9 lengua: 7
💡 .keys() da las claves, .values() los valores y .items() los pares. len() cuenta cuántos pares hay.

Funciones

Una función es un bloque reutilizable: recibe datos (parámetros), trabaja y puede devolver un resultado. Se crea con def:

def saludar(nombre):
    return f"Hola, {nombre}"

print(saludar("Ada"))
print(saludar("Pip"))
Hola, Ada Hola, Pip

🖨️ return vs print (¡importantísimo!)

  • print() → muestra algo en pantalla (para humanos). No sirve para calcular.
  • return → devuelve un valor que el programa puede seguir usando.
def doble(x):
    return x * 2

resultado = doble(5) + doble(3)
print(resultado)  # 10 + 6 = 16
16

⚙️ Varios parámetros y valores por defecto

def area(base, altura=1):  # altura vale 1 si no la pasas
    return base * altura

print(area(5, 3))  # 15
print(area(5))     # 5
15 5
💡 Las variables creadas dentro de una función solo existen ahí dentro (ámbito local). Si las necesitas fuera, devuélvelas con return.

Comprensión de listas

La forma pitónica de crear listas en una sola línea. En vez de esto:

cuadrados = []
for x in range(5):
    cuadrados.append(x ** 2)

…escribes esto (hace exactamente lo mismo):

cuadrados = [x ** 2 for x in range(5)]
print(cuadrados)
[0, 1, 4, 9, 16]

La fórmula es [expresión for variable in iterable]. ¡Y puedes añadir un filtro if!

pares = [x for x in range(10) if x % 2 == 0]
print(pares)
[0, 2, 4, 6, 8]

Errores y debugging 🐛

Todos los programadores cometen errores. La diferencia es que los buenos saben leerlos. Cuando Python falla, muestra un Traceback: léelo de abajo hacia arriba. La última línea dice qué pasó y dónde:

print(nombre)
# NameError: name 'nombre' is not defined. Did you mean: 'nombrar'?

🚨 Los 6 errores más comunes

ErrorSignificaCausa típica
SyntaxErrorCódigo mal escritoFalta :, un paréntesis o una comilla
IndentationErrorIndentación incorrectaBloque sin sangrar o mezclando espacios y tabulador
NameErrorNombre desconocidoVariable con errata o usada antes de crearla
TypeErrorTipos incompatibles"5" + 3 (texto + número)
IndexErrorÍndice fuera de rangoLista de 3 elementos y pides [5]

🛡️ try/except: atrapar errores

Con try puedes atrapar un error para que el programa no se cuelgue:

try:
    numero = int("hola")
    print("Todo bien")
except ValueError:
    print("¡Error atrapado!")
¡Error atrapado!

Si el código del try falla, Python salta al except y el programa sigue vivo.

🔍 Técnicas de detective

  1. Lee el mensaje completo: dice la línea exacta del fallo.
  2. Imprime sospechosos: mete print(variable) para ver qué vale en cada punto.
  3. Comenta por partes: desactiva medio código con # para aislar el problema.
  4. Revisa lo clásico: ¿falta un :? ¿un ==? ¿la indentación?

Programación orientada a objetos (POO)

Hasta ahora usabas datos sueltos. La POO te permite crear tus propios tipos de datos que juntan datos y acciones. La idea en una frase:

  • 🏗️ Clase = el plano (ej: «coche»).
  • 🚗 Objeto = lo construido con el plano (ej: «mi coche rojo»).

🏗️ Crear una clase y objetos

class Perro:
    def __init__(self, nombre):
        self.nombre = nombre

mi_perro = Perro("Toby")
print(mi_perro.nombre)
Toby
  • class Perro: define el plano.
  • __init__ es el constructor: se ejecuta solo al crear el objeto.
  • self representa al propio objeto («yo mismo»). self.nombre = nombre guarda el dato dentro del objeto.
  • Perro("Toby") construye un objeto; mi_perro.nombre lee su dato con un punto.

⚙️ Métodos: lo que sabe hacer un objeto

Un método es una función dentro de la clase. Siempre recibe self como primer parámetro:

class Coche:
    def __init__(self, marca):
        self.marca = marca

    def arrancar(self):
        return "Coche en marcha"

mi_coche = Coche("Tesla")
print(mi_coche.arrancar())
Coche en marcha

👯 Cada objeto tiene sus propios datos

class Robot:
    energia = 100

r1 = Robot()
r2 = Robot()
r1.energia = 50
print(r1.energia, r2.energia)
50 100

Cambiar un dato de r1 no afecta a r2: cada objeto vive su propia vida. Por eso la POO es perfecta para videojuegos (jugadores, enemigos…), cada uno con su energía, posición, etc.

⚠️ Los nombres de clase empiezan por mayúscula por convención: Perro, Coche. Y no olvides el self: ¡casi todos los errores POO de principiantes son por eso!

Sube de nivel: herencia y *args 🚀

👪 Herencia: clases hijas

Una clase puede heredar de otra: la hija recibe todo del padre gratis y puede mejorarlo. Se indica con paréntesis:

class Animal:
    def __init__(self, nombre):
        self.nombre = nombre

class Perro(Animal):  # Perro hereda de Animal
    def hablar(self):
        return "¡Guau!"

p = Perro("Toby")
print(p.nombre)   # heredado del padre
print(p.hablar()) # propio del hijo
Toby ¡Guau!

Si la hija redefine un método del padre, se usa el suyo (override). Y con super() puedes llamar al método del padre desde la hija.

📦 *args: infinitos argumentos

Con *args una función acepta tantos argumentos como quieras: Python los empaqueta en una tupla:

def sumar_todo(*numeros):
    return sum(numeros)

print(sumar_todo(1, 2, 3, 4))  # 10
print(sumar_todo(5, 5))        # 10
10 10

Su primo **kwargs hace lo mismo con argumentos con nombre, empaquetados en un diccionario:

def ficha(**datos):
    for clave, valor in datos.items():
        print(f"{clave}: {valor}")

ficha(nombre="Ada", nivel=5)
nombre: Ada nivel: 5

📄 Lo nuevo: archivos

Con open() tu programa lee y escribe archivos. Siempre con with (se cierra solo) y encoding="utf-8" (para tildes y emojis):

# Escribir (modo "w" = write: crea el archivo o lo vacía)
with open("tareas.txt", "w", encoding="utf-8") as f:
    f.write("[ ] Comprar pan\n")
    f.write("[x] Estudiar Python\n")

# Leer (modo "r" = read)
with open("tareas.txt", "r", encoding="utf-8") as f:
    for linea in f:
        print(linea.strip())
[ ] Comprar pan [x] Estudiar Python
ModoSignifica
"r"Read: leer (falla si no existe → atrápalo con try/except FileNotFoundError)
"w"Write: escribir (crea el archivo o borra lo que había)
"a"Append: añadir al final sin borrar
⚠️ El modo "w" vacía el archivo al abrirlo. Por eso nuestra app carga todo en memoria al empezar y guarda todo junto al salir.

# mis_tareas.py — ¡Mi primera app! 🎉

ARCHIVO = "tareas.txt"


def cargar_tareas():
    tareas = []
    try:
        with open(ARCHIVO, "r", encoding="utf-8") as f:
            for linea in f:
                linea = linea.strip()
                if linea:
                    hecha = linea.startswith("[x]")
                    texto = linea[3:].strip()
                    tareas.append({"texto": texto, "hecha": hecha})
    except FileNotFoundError:
        pass  # primera vez: aún no hay archivo
    return tareas


def guardar_tareas(tareas):
    with open(ARCHIVO, "w", encoding="utf-8") as f:
        for t in tareas:
            marca = "[x]" if t["hecha"] else "[ ]"
            f.write(f"{marca} {t['texto']}\n")


def mostrar_tareas(tareas):
    if not tareas:
        print("(sin tareas)")
        return
    for i in range(len(tareas)):
        marca = "✓" if tareas[i]["hecha"] else "○"
        print(f"{i + 1}. [{marca}] {tareas[i]['texto']}")


def pedir_numero(texto, maximo):
    while True:
        try:
            n = int(input(texto))
            if 1 <= n <= maximo:
                return n
            print(f"Escribe un número del 1 al {maximo}.")
        except ValueError:
            print("Eso no es un número, prueba otra vez.")


def main():
    tareas = cargar_tareas()
    print("=== MIS TAREAS ✅ ===")
    while True:
        print("\n1. Ver  2. Añadir  3. Completar  4. Borrar  5. Salir")
        opcion = input("Elige: ")
        if opcion == "1":
            mostrar_tareas(tareas)
        elif opcion == "2":
            texto = input("Nueva tarea: ").strip()
            if texto:
                tareas.append({"texto": texto, "hecha": False})
                print("¡Añadida!")
        elif opcion == "3":
            if not tareas:
                print("(sin tareas)")
            else:
                mostrar_tareas(tareas)
                n = pedir_numero("¿Cuál completaste? ", len(tareas))
                tareas[n - 1]["hecha"] = True
                print("¡Bien hecho! 🎉")
        elif opcion == "4":
            if not tareas:
                print("(sin tareas)")
            else:
                mostrar_tareas(tareas)
                n = pedir_numero("¿Cuál borras? ", len(tareas))
                borrada = tareas.pop(n - 1)
                print(f"Borrada: {borrada['texto']}")
        elif opcion == "5":
            guardar_tareas(tareas)
            print("¡Hasta luego! Tus tareas están a salvo. 💾")
            break
        else:
            print("Opción no válida.")


main()

Tu primer bot de Telegram 🤖

Vamos a crear un bot que vive en Telegram: responde a comandos (/start, /dado…), juega, suma y guarda notas. ¡Y hablarás con él desde tu móvil!

🤖 1. Crea tu bot con BotFather (5 min)

  1. Abre Telegram y busca @BotFather (el verificado ✓).
  2. Envíale /newbot y sigue sus preguntas: nombre y usuario terminado en bot (ej: mi_primer_bot_123_bot).
  3. Te dará un token (algo como 123456:ABC-DEF...). ¡Cópialo!
  4. Abre tu bot (te da un enlace t.me/...) y pulsa Iniciar.
⚠️ El token es la contraseña de tu bot: quien la tenga lo controla. No lo publiques ni lo subas a internet.

📦 2. Instala la librería

En una terminal escribe: pip install pyTelegramBotAPI. En tu código se importa como telebot.

🧠 3. La idea: decoradores que escuchan

Tu bot es un programa que pregunta sin parar «¿hay mensajes nuevos?» (bot.infinity_polling()). Con decoradores (esas líneas con @) dices qué función responde a cada cosa:

import telebot

bot = telebot.TeleBot("TU_TOKEN")

@bot.message_handler(commands=["start"])  # ← cuando escriban /start…
def saludar(mensaje):                     # …se ejecuta esta función
    bot.reply_to(mensaje, "¡Hola! 🎉")

bot.infinity_polling()  # ← escuchar sin parar

Cada mensaje trae datos útiles: mensaje.text (lo escrito) y mensaje.chat.id (quién lo escribe).

# mi_bot.py — ¡Mi primer bot de Telegram! 🤖
import random
import telebot

TOKEN = "PON_AQUI_TU_TOKEN"
bot = telebot.TeleBot(TOKEN)

notas = {}  # chat_id -> lista de notas


@bot.message_handler(commands=["start"])
def saludar(mensaje):
    bot.reply_to(mensaje, "¡Hola! Soy tu primer bot 🎉\nEscribe /ayuda para ver lo que sé hacer.")


@bot.message_handler(commands=["ayuda"])
def ayuda(mensaje):
    bot.reply_to(mensaje,
        "Puedo hacer esto:\n"
        "/start - Saludarme\n"
        "/ayuda - Ver esta ayuda\n"
        "/dado - Tirar un dado 🎲\n"
        "/suma 5 3 - Sumar números ➕\n"
        "/nota comprar pan - Guardar una nota 📝\n"
        "/notas - Ver tus notas\n"
        "Y si me hablas… ¡te respondo! 💬")


@bot.message_handler(commands=["dado"])
def dado(mensaje):
    numero = random.randint(1, 6)
    bot.reply_to(mensaje, f"🎲 ¡Un {numero}!")


@bot.message_handler(commands=["suma"])
def suma(mensaje):
    try:
        partes = mensaje.text.split()
        a = float(partes[1])
        b = float(partes[2])
        bot.reply_to(mensaje, f"➕ {a} + {b} = {a + b}")
    except (IndexError, ValueError):
        bot.reply_to(mensaje, "Úsalo así: /suma 5 3")


@bot.message_handler(commands=["nota"])
def guardar_nota(mensaje):
    texto = mensaje.text.replace("/nota", "", 1).strip()
    if not texto:
        bot.reply_to(mensaje, "Escribe algo: /nota comprar pan")
        return
    chat = mensaje.chat.id
    if chat not in notas:
        notas[chat] = []
    notas[chat].append(texto)
    bot.reply_to(mensaje, f"📝 Nota guardada ({len(notas[chat])} en total).")


@bot.message_handler(commands=["notas"])
def ver_notas(mensaje):
    chat = mensaje.chat.id
    if chat not in notas or not notas[chat]:
        bot.reply_to(mensaje, "(sin notas)")
        return
    lineas = [f"{i + 1}. {n}" for i, n in enumerate(notas[chat])]
    bot.reply_to(mensaje, "📝 Tus notas:\n" + "\n".join(lineas))


@bot.message_handler(func=lambda m: not m.text.startswith("/"), content_types=["text"])
def responder(mensaje):
    texto = mensaje.text.lower()
    if "hola" in texto:
        bot.reply_to(mensaje, "¡Hola, humano! 👋")
    elif "python" in texto:
        bot.reply_to(mensaje, "¡Python es el mejor lenguaje! 🐍")
    elif "gracias" in texto:
        bot.reply_to(mensaje, "¡De nada! 😊")
    else:
        bot.reply_to(mensaje, f"Me has dicho: {mensaje.text}")


print("Bot en marcha… 🤖")
bot.infinity_polling()

▶️ Cómo ponerlo en marcha

  1. Pega tu token en TOKEN = "..." y guarda como mi_bot.py.
  2. Ejecuta python mi_bot.py y deja la terminal abierta (si la cierras, el bot se duerme 😴).
  3. Habla con tu bot en Telegram: /start, /dado, /suma 5 3…

🚀 Retos de ampliación

  1. /moneda: cara o cruz con random.choice(["cara", "cruz"]).
  2. /chiste: guarda una lista de chistes y envía uno al azar.
  3. Notas eternas: guárdalas en un archivo (¡como en el taller de la app!).
  4. Más charla: responde a «adiós», «quién eres» o tu nombre.

Tu primera web con Flask 🌐

Vamos a crear un muro de mensajes que funciona en el navegador: Python con Flask escucha peticiones y responde páginas. ¡El salto de programas para ti a apps para el mundo!

🧠 La idea en 30 segundos

  • Tu programa es un servidor: escucha en localhost:5000 («mi PC, puerta 5000»).
  • Cada @app.route(...) es una dirección: al visitarla, se ejecuta su función y devuelve una página.
  • El diseño vive en plantillas (templates/) con huecos {{ ... }} que Python rellena.
  • Los formularios envían datos (POST) que lees con request.form.

📦 Instalación y hola mundo

En una terminal: pip install flask. Y esto ya es una web:

from flask import Flask

app = Flask(__name__)

@app.route("/")
def inicio():
    return "<h1>¡Mi primera web con Python! 🐍</h1>"

if __name__ == "__main__":
    app.run(debug=True)

Ejecuta python app.py, abre localhost:5000… ¡ahí está! 🎉 (debug=True recarga solo al guardar; se para con Ctrl + C.)

# app.py — ¡Mi primera web con Flask! 🌐
from flask import Flask, render_template, request, redirect

app = Flask(__name__)

MENSAJES = ["¡Bienvenido al muro! 🎉"]


@app.route("/")
def inicio():
    return render_template("index.html", mensajes=MENSAJES)


@app.route("/saludo/<nombre>")
def saludo(nombre):
    return f"<h1>¡Hola, {nombre}! 👋</h1><p><a href='/'>Volver al muro</a></p>"


@app.route("/nuevo", methods=["POST"])
def nuevo():
    texto = request.form.get("texto", "").strip()
    if texto:
        MENSAJES.append(texto)
    return redirect("/")


@app.route("/borrar/<int:indice>", methods=["POST"])
def borrar(indice):
    if 0 <= indice < len(MENSAJES):
        MENSAJES.pop(indice)
    return redirect("/")


if __name__ == "__main__":
    app.run(debug=True)
